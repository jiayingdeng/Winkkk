## 🎯 **核心概念解析**

### 💡 **什么是时间序列模式**

时间序列模式是一种将视频中的**多个关键时刻**提取出来，按照**时间顺序清晰排列**在一张图片中的融合技术。

#### **一句话理解**
> 把一个完整的动作过程，分解成多个清晰的瞬间，像连环画一样展示在一张图片里

#### **视觉效果对比**
```
传统视频 vs 时间序列图片:

📱 传统视频：
[播放按钮] ▶️ 需要播放才能看到完整过程
- 无法一眼看全整个动作
- 难以分析具体细节
- 不便于分享和保存

📸 时间序列图片：
┌─────────────────────────────────────┐
│  👤1   👤2   👤3   👤4   👤5        │
│  准备   起跳   空中   转体   落地      │
│  所有关键动作一目了然                │
│  完美的教学演示效果                  │
└─────────────────────────────────────┘
```

### 🎬 **技术原理图解**

#### **输入处理流程**
```
原始视频 (5-30秒)
        ↓
    智能关键帧提取
        ↓
    [帧1] [帧2] [帧3] [帧4] [帧5]
     0s    1s    2s    3s    4s
```

#### **智能布局算法**
```
布局分析过程：
1️⃣ 运动轨迹检测
   - 水平运动：左→右 排列
   - 垂直运动：上→下 排列  
   - 弧形运动：弧形路径排列

2️⃣ 最优间距计算
   - 避免图像重叠
   - 保持视觉美观
   - 符合运动节奏

3️⃣ 画布尺寸优化
   - 自动计算最小画布
   - 支持不同屏幕比例
   - 预留边距空间
```

#### **1. 清晰独立性**
- 每个时间点的图像都**完整清晰**
- 没有重叠、模糊或透明效果

#### **2. 时间叙事性**
- 按照**时间顺序**排列
- 形成清晰的**故事线**
- 像连环画一样易于理解

#### **3. 教学演示性**
- 完美的**动作分解**效果
- 适合**教学分析**使用

#### **4. 艺术美观性**

```swift
class AdvancedTimeSequenceComposer {
    
    // 长时间序列专用处理
    func processLongTimeSequence(
        images: [UIImage],
        sceneType: SceneType
    ) -> UIImage {
        
        switch sceneType {
        case .lunarEclipse:
            // 月食：突出月亮轨迹，背景保持夜空
            return composeMoonTrajectory(images)
            
        case .sunrise:
            // 日出：展现天空色彩变化
            return composeSkyGradient(images)
            
        case .plantGrowth:
            // 植物：突出生长变化
            return composeGrowthSequence(images)
        }
    }
    
    private func composeMoonTrajectory(_ images: [UIImage]) -> UIImage {
        // 固定机位 = 背景完全一致
        // 只需要简单的透明度叠加
        return blendImagesWithAlpha(images, mode: .moonTrail)
    }
}
```

```swift
// iOS原生CoreImage可以实现的背景差分
func basicBackgroundSubtraction(_ frames: [UIImage]) -> [UIImage] {
    
    // 1. 使用CIDifferenceBlendMode进行帧间差分
    let differenceFilter = CIFilter(name: "CIDifferenceBlendMode")!
    
    // 2. 基于差分结果创建mask
    let thresholdFilter = CIFilter(name: "CIColorThreshold")!
    
    // 3. 使用mask进行图像分离
    let maskFilter = CIFilter(name: "CIBlendWithMask")!
    
    var processedFrames: [UIImage] = []
    var referenceBackground: UIImage!
    
    for (index, frame) in frames.enumerated() {
        if index == 0 {
            // 第一帧作为背景参考
            referenceBackground = frame
            continue
        }
        
        // 计算与背景的差异
        differenceFilter.setValue(CIImage(image: frame), forKey: kCIInputImageKey)
        differenceFilter.setValue(CIImage(image: referenceBackground), forKey: kCIInputBackgroundImageKey)
        
        // 生成二值化mask
        let diffResult = differenceFilter.outputImage!
        thresholdFilter.setValue(diffResult, forKey: kCIInputImageKey)
        
        // 应用mask提取主体
        let mask = thresholdFilter.outputImage!
        maskFilter.setValue(CIImage(image: frame), forKey: kCIInputImageKey)
        maskFilter.setValue(mask, forKey: kCIInputMaskImageKey)
        
        let extractedSubject = maskFilter.outputImage!
        processedFrames.append(UIImage(ciImage: extractedSubject))
    }
    
    return processedFrames
}
```

```swift
/// 运动模式类型
enum MotionPattern {
    case horizontal(direction: Direction)  // 水平运动
    case vertical(direction: Direction)    // 垂直运动  
    case circular(center: CGPoint, radius: CGFloat)  // 圆弧运动
    case complex(points: [CGPoint])        // 复杂轨迹
}

enum Direction {
    case leftToRight, rightToLeft
    case topToBottom, bottomToTop
}

class MotionAnalyzer {
    
    /// 分析运动轨迹模式
    func analyzeMotionPattern(frames: [TimeSequenceFrame]) -> MotionPattern {
        
        // 1. 计算每帧的运动主体中心点
        var centroids: [CGPoint] = []
        for frame in frames {
            let centroid = calculateCentroid(of: frame.image)
            centroids.append(centroid)
        }
        
        // 2. 分析轨迹类型
        if isHorizontalMotion(centroids) {
            let direction = centroids.first!.x < centroids.last!.x ? 
                Direction.leftToRight : Direction.rightToLeft
            return .horizontal(direction: direction)
            
        } else if isVerticalMotion(centroids) {
            let direction = centroids.first!.y < centroids.last!.y ? 
                Direction.topToBottom : Direction.bottomToTop
            return .vertical(direction: direction)
            
        } else if isCircularMotion(centroids) {
            let (center, radius) = fitCircle(to: centroids)
            return .circular(center: center, radius: radius)
            
        } else {
            return .complex(points: centroids)
        }
    }
    
    /// 计算图像中运动主体的中心点
    private func calculateCentroid(of image: UIImage) -> CGPoint {
        
        // 方法1: 简单重心计算 (MVP版本)
        return CGPoint(x: image.size.width / 2, y: image.size.height / 2)
        
        // 方法2: 基于亮度对比 (优化版本)
        // return calculateBrightnessCentroid(image)
        
        // 方法3: 基于Vision框架物体检测 (高级版本)  
        // return detectObjectCentroid(image)
    }
    
    /// 判断是否为水平运动
    private func isHorizontalMotion(_ points: [CGPoint]) -> Bool {
        guard points.count >= 2 else { return false }
        
        let xVariance = calculateVariance(points.map { $0.x })
        let yVariance = calculateVariance(points.map { $0.y })
        
        return xVariance > yVariance * 2.0  // X方向变化明显大于Y方向
    }
    
    /// 判断是否为垂直运动
    private func isVerticalMotion(_ points: [CGPoint]) -> Bool {
        guard points.count >= 2 else { return false }
        
        let xVariance = calculateVariance(points.map { $0.x })
        let yVariance = calculateVariance(points.map { $0.y })
        
        return yVariance > xVariance * 2.0  // Y方向变化明显大于X方向
    }
    
    /// 判断是否为圆弧运动
    private func isCircularMotion(_ points: [CGPoint]) -> Bool {
        guard points.count >= 3 else { return false }
        
        // 尝试拟合圆形，计算拟合度
        let (_, radius) = fitCircle(to: points)
        let avgDistance = calculateAverageDistanceFromCenter(points)
        
        // 如果点都大致在同一个圆上，认为是圆弧运动
        let deviation = abs(radius - avgDistance) / radius
        return deviation < 0.3  // 允许30%的偏差
    }
}
```

```swift
/// 布局结果数据结构
struct LayoutResult {
    let positions: [CGPoint]    // 每张图片的位置
    let canvasSize: CGSize      // 画布总尺寸
    let imageSize: CGSize       // 统一的图片尺寸
    let spacing: CGFloat        // 图片间距
}

class TimeSequenceLayoutEngine {
    
    /// 计算最优布局
    func calculateOptimalLayout(
        frames: [TimeSequenceFrame],
        motionPattern: MotionPattern,
        targetSize: CGSize = CGSize(width: 1080, height: 1080)
    ) -> LayoutResult {
        
        switch motionPattern {
        case .horizontal(let direction):
            return calculateHorizontalLayout(frames: frames, direction: direction, targetSize: targetSize)
            
        case .vertical(let direction):
            return calculateVerticalLayout(frames: frames, direction: direction, targetSize: targetSize)
            
        case .circular(let center, let radius):
            return calculateCircularLayout(frames: frames, center: center, radius: radius, targetSize: targetSize)
            
        case .complex(let points):
            return calculateComplexLayout(frames: frames, points: points, targetSize: targetSize)
        }
    }
    
    /// 水平布局计算
    private func calculateHorizontalLayout(
        frames: [TimeSequenceFrame],
        direction: Direction,
        targetSize: CGSize
    ) -> LayoutResult {
        
        let frameCount = frames.count
        let imageSize = calculateOptimalImageSize(
            frameCount: frameCount, 
            targetSize: targetSize, 
            isHorizontal: true
        )
        
        // 计算间距和起始位置
        let totalImageWidth = CGFloat(frameCount) * imageSize.width
        let availableSpaceWidth = targetSize.width - totalImageWidth
        let spacing = availableSpaceWidth / CGFloat(frameCount + 1)
        
        var positions: [CGPoint] = []
        let startY = (targetSize.height - imageSize.height) / 2
        
        for i in 0..<frameCount {
            let x = spacing + CGFloat(i) * (imageSize.width + spacing)
            let position = CGPoint(x: x, y: startY)
            positions.append(position)
        }
        
        // 如果是从右到左，反转位置
        if direction == .rightToLeft {
            positions.reverse()
        }
        
        return LayoutResult(
            positions: positions,
            canvasSize: targetSize,
            imageSize: imageSize,
            spacing: spacing
        )
    }
    
    /// 圆弧布局计算 (高级功能)
    private func calculateCircularLayout(
        frames: [TimeSequenceFrame],
        center: CGPoint,
        radius: CGFloat,
        targetSize: CGSize
    ) -> LayoutResult {
        
        let frameCount = frames.count
        let imageSize = calculateOptimalImageSize(
            frameCount: frameCount,
            targetSize: targetSize,
            isHorizontal: false
        )
        
        // 计算弧度步长
        let totalAngle = CGFloat.pi * 1.5  // 270度弧形
        let angleStep = totalAngle / CGFloat(frameCount - 1)
        let startAngle = -CGFloat.pi / 4   // 从-45度开始
        
        var positions: [CGPoint] = []
        
        for i in 0..<frameCount {
            let angle = startAngle + CGFloat(i) * angleStep
            let x = center.x + radius * cos(angle) - imageSize.width / 2
            let y = center.y + radius * sin(angle) - imageSize.height / 2
            positions.append(CGPoint(x: x, y: y))
        }
        
        return LayoutResult(
            positions: positions,
            canvasSize: targetSize,
            imageSize: imageSize,
            spacing: radius * angleStep  // 弧长作为间距
        )
    }
    
    /// 计算最优图片尺寸
    private func calculateOptimalImageSize(
        frameCount: Int,
        targetSize: CGSize,
        isHorizontal: Bool
    ) -> CGSize {
        
        let padding: CGFloat = 40  // 边距
        let minSpacing: CGFloat = 20  // 最小间距
        
        if isHorizontal {
            // 水平排列：宽度平分，高度自适应
            let availableWidth = targetSize.width - padding * 2 - CGFloat(frameCount - 1) * minSpacing
            let imageWidth = availableWidth / CGFloat(frameCount)
            let imageHeight = min(imageWidth * 1.2, targetSize.height - padding * 2)  // 保持合理比例
            
            return CGSize(width: imageWidth, height: imageHeight)
            
        } else {
            // 垂直排列：高度平分，宽度自适应
            let availableHeight = targetSize.height - padding * 2 - CGFloat(frameCount - 1) * minSpacing
            let imageHeight = availableHeight / CGFloat(frameCount)
            let imageWidth = min(imageHeight * 0.8, targetSize.width - padding * 2)
            
            return CGSize(width: imageWidth, height: imageHeight)
        }
    }
}
```

```swift
                    drawSequenceNumber(
                        context: cgContext,
                        number: index + 1,
                        rect: rect
                    )
                }
            }

        switch options.backgroundStyle {
        case .solid(let color):
            context.setFillColor(color.cgColor)
            context.fill(CGRect(origin: .zero, size: size))
            
        case .gradient(let colors):
            drawGradientBackground(context: context, size: size, colors: colors)
            
        case .transparent:
            // 透明背景，不做处理
            break
        }
    }

        context.saveGState()
        
        context.setShadow(
            offset: CGSize(width: 2, height: 2),
            blur: 4,

        )
        
        context.setFillColor(UIColor.white.cgColor)
        context.fill(rect)
        
        context.restoreGState()

            y: rect.maxY - textSize.height - 8,

    }
```

```swift
/// 时间序列合成器 - 主控制器
class TimeSequenceComposer {
    
    private let screenshotEngine = ScreenshotEngine()
    private let motionAnalyzer = MotionAnalyzer()
    private let layoutEngine = TimeSequenceLayoutEngine()
    private let renderer = TimeSequenceRenderer()
    
    /// 从视频生成时间序列图片
    /// - Parameters:
    ///   - videoURL: 视频文件URL
    ///   - frameCount: 提取帧数 (4-8张)
    ///   - completion: 完成回调
    func generateTimeSequence(
        from videoURL: URL,
        frameCount: Int = 5,
        completion: @escaping (Result<UIImage, TimeSequenceError>) -> Void
    ) {
        
        // Step 1: 提取关键帧
        screenshotEngine.extractTimeSequenceFrames(
            from: videoURL,
            frameCount: frameCount
        ) { [weak self] result in
            
            switch result {
            case .success(let frames):
                self?.processFrames(frames, completion: completion)
                
            case .failure(let error):
                completion(.failure(.frameExtractionFailed(error)))
            }
        }
    }
    
    /// 处理提取的帧
    private func processFrames(
        _ frames: [TimeSequenceFrame],
        completion: @escaping (Result<UIImage, TimeSequenceError>) -> Void
    ) {
        
        DispatchQueue.global(qos: .userInitiated).async { [weak self] in
            guard let self = self else { return }
            
            do {
                // Step 2: 分析运动轨迹
                let motionPattern = self.motionAnalyzer.analyzeMotionPattern(frames: frames)
                
                // Step 3: 计算布局
                let layout = self.layoutEngine.calculateOptimalLayout(
                    frames: frames,
                    motionPattern: motionPattern
                )
                
                // Step 4: 渲染合成图
                let resultImage = self.renderer.renderTimeSequence(
                    frames: frames,
                    layout: layout
                )
                
                DispatchQueue.main.async {
                    completion(.success(resultImage))
                }
                
            } catch {
                DispatchQueue.main.async {
                    completion(.failure(.processingFailed(error.localizedDescription)))
                }
            }
        }
    }
}

/// 时间序列错误类型
enum TimeSequenceError: Error {
    case frameExtractionFailed(ScreenshotError)
    case processingFailed(String)
    case invalidInput
    
    var localizedDescription: String {
        switch self {
        case .frameExtractionFailed(let error):
            return "帧提取失败: \(error.localizedDescription)"
        case .processingFailed(let message):
            return "处理失败: \(message)"
        case .invalidInput:
            return "输入数据无效"
        }
    }
}
```
