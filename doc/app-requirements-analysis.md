# 视频截图App需求分析文档

## 📱 App概述

基于对Wink App的调研分析，开发一款专注于**视频截图**的iOS App，核心定位是帮助小红书等平台的精致女性用户从视频中提取高质量的静态图片。

## 🎯 核心功能拆解

### 1. 录像模块
- 全屏相机界面（占屏幕最大比例）
- 录制按钮和基础控制
- 录制完成后的选择：直接编辑 vs 保存到相册

### 2. 视频管理模块  
- App内置相册（存储用户录制的视频）
- 视频选择界面（缩略图展示）
- 支持从相册导入视频

### 3. 视频截图模块
- 视频播放器
- 精确时间轴控制
- 逐帧定位功能
- 截图预览

### 4. 画质修复模块
- AI画质增强处理
- 修复前后对比
- 多种修复强度选择

## 🎨 UI设计方案（3个版本）

### 方案一：「小红书风格」- 简约清新
- **色彩**：白色主色调 + 粉色点缀 (#FFB6C1)
- **设计语言**：扁平化设计，圆角卡片
- **特点**：
  - 底部导航采用线性图标
  - 录制按钮设计成大圆形，粉色渐变
  - 时间轴采用细线条设计，拖拽点为粉色小圆点
  - 截图按钮设计成相机图标形状

### ✅ 方案二：「梦幻少女」- 浪漫柔美（当前采用）
- **色彩**：渐变背景（粉紫色 #E6B3FF → 粉色 #FFD1DC）
- **设计语言**：毛玻璃效果，柔和阴影
- **特点**：
  - 使用磨砂玻璃背景效果 (`UIVisualEffectView`)
  - 按钮采用胶囊形状，带有微妙的阴影
  - 录制按钮周围有呼吸光效动画 (`CAAnimationGroup`)
  - 截图成功后有心形动画反馈 (`CAEmitterLayer`)

### 方案三：「现代优雅」- 高级质感
- **色彩**：深色模式 + 玫瑰金点缀 (#E8B4A0)  
- **设计语言**：现代简约，注重留白
- **特点**：
  - 支持深浅色主题切换
  - 使用更多负空间，突出核心功能
  - 录制按钮采用金属质感设计
  - 界面过渡动画更加流畅精致

## 🛠️ 画质修复技术分析

### 方案一：Core ML + 预训练模型（未来实现）
- **超分辨率模型**：如 Real-ESRGAN、EDSR
- **去噪模型**：用于移除视频压缩噪点
- **优点**：效果好，处理速度快
- **缺点**：模型文件较大（10-50MB）

### ✅ 方案二：传统图像处理（当前实现）
基于快速实现和简单易用的考虑，先采用传统图像处理算法：

#### **核心算法组合**
1. **USM锐化 (Unsharp Mask)**
   - 增强图像边缘清晰度
   - 参数可调：锐化强度、半径、阈值

2. **直方图均衡化**
   - 自动调整对比度和亮度
   - 提升图像整体观感

3. **高斯去噪**
   - 减少视频压缩产生的噪点
   - 保持图像细节的同时平滑噪声

4. **色彩增强**
   - 调整饱和度和色温
   - 让图片更加鲜艳生动

#### **实现优势**
- **处理速度快**：< 0.5秒完成处理
- **无需额外模型**：使用iOS原生Core Image框架
- **文件大小小**：不增加App体积
- **效果可控**：用户可选择修复强度（轻度/中度/重度）
- **实时预览**：支持参数调整的即时效果预览

#### **预留扩展性**
- 架构设计支持未来集成Core ML模型
- 算法模块化，便于后续升级

### ✅ 页面导航架构（确定方案）

#### **混合导航模式：主流程导航 + 功能模块导航**

**第一层：主入口（无TabBar）**
```
启动页 → 主相机页面（MainCameraViewController）
```
- 主相机页面作为唯一入口，占据全屏
- 底部浮层按钮：[相册] [录制] [设置]

**第二层：功能流程导航**
- **录制流程**（Modal呈现）：主相机页 → 录制中页面 → 录制完成选择页
- **编辑流程**（Navigation推送）：主相机页 → 相册页面 → 视频编辑页 → 画质修复页
- **设置流程**（Modal呈现）：主相机页 → 设置页面

#### **导航优势**
- 流程导向，符合工具型App特点
- 全屏沉浸的相机体验
- 简洁界面，减少用户认知负担
- 适合女性用户的操作习惯

## 💡 技术实现细节建议

### 📁 文件格式支持策略

#### **✅ 输入视频格式（推荐支持）**
- **MP4** - 最通用格式，小红书、抖音导出标准 ⭐⭐⭐⭐⭐
- **MOV** - iPhone录制原生格式，质量最高 ⭐⭐⭐⭐⭐  
- **M4V** - iTunes和其他App导入格式 ⭐⭐⭐
- **暂不支持**: AVI、WMV、FLV（需要额外转换，增加复杂度）

#### **✅ 输出图片格式设置**
- **默认格式**: JPEG 85% 质量（平衡质量和文件大小）
- **高质量选项**: JPEG 95% 或 PNG（用户可选）
- **快速分享模式**: JPEG 75%（文件小，上传快）
- **暂不考虑**: HEIC（兼容性问题，部分平台不支持）

### 📱 设备兼容性规划

#### **✅ 系统版本支持**
- **目标版本**: iOS 15.0+
- **覆盖率**: 90%+用户群体
- **技术优势**: AVFoundation API更稳定，Core Image性能更好

#### **✅ 设备性能分级策略**
```swift
enum DevicePerformance {
    case high    // iPhone 13+, A15+芯片 - 4K录制+实时预览
    case medium  // iPhone 11-12, A13-A14芯片 - 1080P录制+基础修复  
    case low     // iPhone SE, iPhone X-XS, A12及以下 - 720P录制+简化功能
}
```

#### **✅ iPad适配决策**
- **当前策略**: 暂不专门适配，但确保iPhone版本在iPad上可用
- **原因**: 开发资源优先iPhone体验，后续根据用户反馈决定
