# 拼图和画质修复功能集成方案

## 📊 现状分析

### 🧩 拼图功能现状
- 位置：`ScreenshotProcessingViewController` → `CollageViewController`
- 支持多种布局模板（网格、水平、垂直、马赛克等）
- 可以调整比例、编辑图片参数
- **终端操作**：完成后只能保存/分享，无法进行后续处理

### ✨ 画质修复功能现状
- 单图修复：`ImageEnhanceViewController`（轻度/中度/重度）
- 批量修复：`BatchImageEnhanceViewController`（支持选择性批量处理）
- **终端操作**：修复完成后只能保存/分享，无法继续拼图

## 🚩 核心问题诊断

当前两个功能都是**孤立的终端操作**，缺乏功能间的流转机制，导致用户无法：
1. 拼图完成后继续优化画质
2. 画质修复后重新组合拼图
3. 进行多轮优化处理

## 🚀 解决方案：环形工作流设计

### 核心理念
创建一个**可循环的处理链条**，让用户在拼图和画质修复之间自由切换，支持多轮优化：

```
原始截图 → 拼图 → 画质修复 → 再拼图 → 再修复 → ... → 最终结果
     ↗                              ↙
    画质修复 → 拼图 → 画质修复 → 拼图
```

### 具体交互流程

**1. 拼图后继续画质修复**
```
CollageViewController（拼图完成）
├── 保存拼图 ✓
├── 分享拼图 ✓
└── 🆕 画质修复拼图 → ImageEnhanceViewController
    └── 修复完成后可选择：
        ├── 保存最终结果
        ├── 分享最终结果
        └── 🔄 返回拼图编辑（用修复后的图）
```

**2. 画质修复后继续拼图**
```
BatchImageEnhanceViewController（批量修复完成）
├── 保存修复图片 ✓
├── 分享修复图片 ✓
└── 🆕 创建拼图 → CollageViewController（使用修复后的图片）
    └── 拼图完成后可选择：
        ├── 保存拼图
        ├── 分享拼图
        └── 🔄 继续画质修复拼图
```

   ```swift
       let completedImages = enhanceItems.compactMap { item in
           return item.processingState == .completed ? item.enhancedImage : nil
       }
       
       guard completedImages.count > 1 else {
           showAlert(title: "无法创建拼图", message: "至少需要2张修复完成的图片才能创建拼图")
           HapticFeedbackManager.shared.notificationWarning()
           return

       HapticFeedbackManager.shared.buttonTap()
       
       // 跳转到拼图创建页面
       let collageVC = CollageViewController(images: completedImages)
       collageVC.sourceType = .fromEnhancedImages // 标记来源
       navigationController?.pushViewController(collageVC, animated: true)
   }
   ```

   ```swift
   }
   ```

   ```swift
       let recommendation = workflowRecommendationEngine.getRecommendation(for: screenshots)
       recommendation.execute(from: self, with: screenshots)
   }
   ```

### **第四步：创建工作流数据模型和管理类**

#### 新建文件：`Winkkk/Models/WorkflowModels.swift`

**内容概要：**
```swift
// 工作流步骤枚举
enum WorkflowStep {
    case originalScreenshots
    case collageCreated(UIImage)
    case imageEnhanced([UIImage])
    case collageFromEnhanced(UIImage)
}

// 工作流推荐引擎
class WorkflowRecommendationEngine {
    func getRecommendation(for screenshots: [ScreenshotItem]) -> WorkflowRecommendation
}

// 推荐结果模型
struct WorkflowRecommendation {
    let title: String
    let description: String  
    let actionTitle: String
    let execute: (UIViewController, [ScreenshotItem]) -> Void
}
```
