# 权限卡片主题适配修复报告

## 问题描述

权限请求页面在**简约浅色主题**下显示时，权限卡片区域几乎看不清楚，缺乏足够的对比度。

### 具体问题

1. **容器背景色**：使用硬编码的白色半透明 `UIColor.white.withAlphaComponent(0.1)`，在浅色背景上几乎不可见
2. **边框颜色**：使用硬编码的白色半透明边框 `UIColor.white.withAlphaComponent(0.2)`，在浅色背景上不够明显
3. **缺少主题切换监听**：主题切换时权限卡片颜色不会自动更新

### 影响范围

- 权限请求页面（PermissionRequestViewController）
- 影响用户在简约浅色主题下的引导体验

## 解决方案

### 1. 在 ThemeManager 中添加权限卡片专属颜色

**文件**：`Winkkk/Managers/ThemeManager.swift`

添加了两个新的主题感知颜色属性：

```swift
/// 权限卡片容器背景
static var permissionCardBackground: UIColor {
    switch shared.currentTheme {
    case .dreamyGirl:
        return UIColor.white.withAlphaComponent(0.1) // 白色半透明（在深色渐变背景上）
    case .lightMinimal:
        return UIColor(red: 28/255, green: 28/255, blue: 30/255, alpha: 0.05) // 深色半透明（在浅色背景上）
    }
}

/// 权限卡片边框颜色
static var permissionCardBorder: UIColor {
    switch shared.currentTheme {
    case .dreamyGirl:
        return UIColor.white.withAlphaComponent(0.2) // 白色半透明边框
    case .lightMinimal:
        return UIColor(red: 28/255, green: 28/255, blue: 30/255, alpha: 0.15) // 深色半透明边框
    }
}
```

### 2. 更新 PermissionCard 使用主题颜色

**文件**：`Winkkk/Controllers/PermissionRequestViewController.swift`

#### 修改前：
```swift
containerView.backgroundColor = UIColor.white.withAlphaComponent(0.1)
containerView.layer.borderColor = UIColor.white.withAlphaComponent(0.2).cgColor
```

#### 修改后：
```swift
containerView.backgroundColor = ThemeManager.permissionCardBackground
containerView.layer.borderColor = ThemeManager.permissionCardBorder.cgColor
```

### 3. 添加主题切换监听

在 `PermissionCard` 类中添加了主题切换监听：

```swift
init(permission: PermissionData) {
    self.permission = permission
    super.init(frame: .zero)
    setupUI()
    setupConstraints()
    setupGestures()
    configureContent()
    updatePermissionStatus()
    
    // 监听主题切换
    NotificationCenter.default.addObserver(
        self,
        selector: #selector(handleThemeChange),
        name: .themeDidChange,
        object: nil
    )
}

deinit {
    NotificationCenter.default.removeObserver(self)
}

@objc private func handleThemeChange() {
    // 更新容器背景和边框
    containerView.backgroundColor = ThemeManager.permissionCardBackground
    containerView.layer.borderColor = ThemeManager.permissionCardBorder.cgColor
    
    // 更新文本颜色
    titleLabel.textColor = ThemeManager.overlayTextWhite
    descriptionLabel.textColor = ThemeManager.overlaySecondaryText
    statusLabel.textColor = ThemeManager.overlayTextWhite
}
```

## 效果对比

### 梦幻少女主题
- **背景**：白色半透明 (alpha: 0.1) - 在深色渐变背景上清晰可见
- **边框**：白色半透明 (alpha: 0.2) - 提供轻微的边界感

### 简约浅色主题
- **背景**：深灰黑半透明 (alpha: 0.05) - 在浅色背景上形成对比
- **边框**：深灰黑半透明 (alpha: 0.15) - 清晰的边界线
- **文本**：黑色系 - 优秀的可读性

## 技术亮点

1. **主题统一性**：权限卡片颜色与整体主题体系保持一致
2. **动态响应**：支持运行时主题切换，无需重启应用
3. **代码复用**：使用 ThemeManager 统一管理颜色，便于维护
4. **内存安全**：在 deinit 中正确移除通知监听
